Admin · AI Répondeur

Crée et gère l'assistante vocale de chaque client. Les données restent chez Vapi (assistantes) ; rien n'est stocké ici à part ta clé admin.

1. Connexion

Première mise en route (une seule fois)
  1. Crée un compte sur vapi.ai (assistantes vocales) et copie ta clé API privée (« Private Key »).
  2. Crée un compte Twilio, achète un numéro français (pièces justificatives demandées) et note Account SID et Auth Token.
  3. Dans Netlify → ton projet → Project configuration → Environment variables, ajoute : VAPI_API_KEY, TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, REPONDEUR_ADMIN_KEY et REPONDEUR_WEBHOOK_SECRET (deux longues phrases secrètes inventées), puis redéploie.
  4. Facultatif : TWILIO_SMS_FROM (expéditeur des SMS, « Vortex » par défaut).
